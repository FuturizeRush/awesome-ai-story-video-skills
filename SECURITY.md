# Security and Listing Corrections

This repository is an index. It does not distribute, run, or claim to security-review the upstream projects it lists.

Report a vulnerability in a listed project through that project's own security channel. Do not disclose credentials, private exploit details, or unreleased vulnerability information in this repository.

If an entry has changed ownership, is compromised, has a materially incorrect license description, or should be removed from this list, open an issue with public evidence that maintainers can verify.
