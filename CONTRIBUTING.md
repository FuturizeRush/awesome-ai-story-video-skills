# Contributing

Submit one project per pull request and include:

- canonical repository URL and exact reviewed commit;
- current stars, license, archived state, and last push date;
- whether it is an agent Skill, library, model, or application;
- sponsorship, affiliate, paid API, or commercial-license disclosures;
- install hooks, process/network behavior, bind addresses, default credentials, secret handling, checkpoint loading, and update behavior;
- commands/tests actually run and known gaps.

Projects below 1,000 stars are out of scope for the default curated list. Do not include copied Skill content when its license does not permit redistribution. Installation or audit interest alone is not a recommendation criterion.
