# Contributing

Add one project per pull request. Include its GitHub URL, category, license, current star count, last meaningful activity, and upstream evidence for the claimed creative workflow. Keep entries alphabetical within each section.

Submissions must meet the criteria in [README.md](README.md). Keep descriptions factual and concise. Do not include referral links, sponsored copy, copied skill content, or project-specific setup notes. Classify a project by its primary independent capability; do not imply that separate projects have an upstream integration unless that integration is documented. Below-threshold projects require an explicit maintainer exception and must be marked as such in the README. Entries that require hosted providers, paid APIs, non-open model weights, or separately licensed components must state that boundary in their description.
