# Contributing

Add one project per pull request. Include its GitHub URL, category, license, and a short description of how it supports story or learning-video production, or the design and marketing work that produces those assets.

Submissions must meet the criteria in [README.md](README.md). Keep descriptions factual and concise. Do not include referral links, sponsored copy, copied skill content, or project-specific setup notes. Below-threshold projects require an explicit maintainer exception and must be marked as such in the README. Entries that require hosted providers, paid APIs, non-open model weights, or separately licensed components must state that boundary in their description.
